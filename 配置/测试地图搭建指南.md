# 地球Online - 测试地图搭建指南

## 一、地图基础设置

### 1.1 创建关卡
1. 打开UE5编辑器，File → New Level
2. 选择 **Empty Level**（空关卡），避免默认模板的多余设置
3. 保存为 `TestMap.umap`，路径：`Content/Maps/TestMap`

### 1.2 世界设置
- World Settings → Game Mode：选择 `GameMode Base`（测试阶段不需要自定义GameMode）
- 关闭默认的天空球和大气雾（我们手动配置）

---

## 二、光照系统配置（Lumen + 硬件光追）

### 2.1 定向光源（太阳）
在场景中放置 **Directional Light**：
- Intensity：**10.0**（lux，UE5默认单位）
- Light Color：**#FFF4E6**（暖白色，模拟正午阳光）
- Source Angle：**0.5**
- 勾选 **Atmosphere/Fog Sun Light**
- 勾选 **Cast Shadows**
- Shadow Resolution Scale：**4.0**
- 勾选 **Cast Ray Tracing Shadows**（硬件光追阴影）

### 2.2 天空光源（Sky Light）
放置 **Sky Light**：
- Source Type：**SLS_CapturedScene**（实时捕获场景）
- Intensity：**1.0**
- 勾选 **Real Time Capture**
- 勾选 **Cast Ray Tracing Shadows**

### 2.3 天空大气（Sky Atmosphere）
放置 **Sky Atmosphere** 组件：
- 行星半径：**6371km**（真实地球半径）
- 大气高度：**100km**
-  Rayleigh Scattering：**(0.170212, 0.4096, 1.0)**（瑞利散射，蓝色天空）
-  Mie Scattering：**(0.003906, 0.003906, 0.003906)**
- 勾选 **Convert Body to Seed Points**

### 2.4 指数高度雾（Exponential Height Fog）
放置 **Exponential Height Fog**：
- Fog Density：**0.005**
- Fog Height Falloff：**0.2**
- Fog Color：**#B8D4E8**（淡蓝色）
- 勾选 **Volumetric Fog**（体积雾）
- Volumetric Fog Scattering Distribution：**0.2**

### 2.5 Lumen 全局光照验证
- 控制台输入：`r.Lumen.DiffuseIndirect.Allow 1`
- 控制台输入：`r.Lumen.Reflections.Allow 1`
- 视图模式切换到 **Lumen Scene** 验证Lumen是否正常工作

---

## 三、后期处理体积（Post Process Volume）

放置 **Post Process Volume**，设置为 **Unbound**（全局生效）：

### 3.1 曝光（Exposure）
- Metering Mode：**Manual**（手动曝光，测试阶段更稳定）
- Exposure Compensation：**0.0**
- 或者使用 Auto Exposure：
  - Min Brightness：**-2.0**
  - Max Brightness：**2.0**
  - Speed Up：**3.0**
  - Speed Down：**1.0**

### 3.2 镜头光晕（Bloom）
- 勾选 **Bloom**
- Intensity：**0.6**
- Threshold：**1.0**
- 1/2/3/4/5 Size：分别设置为 **0.5, 0.7, 0.9, 1.1, 1.3**

### 3.3 景深（Depth of Field）
- 测试阶段关闭，或设置为：
  - Method：**BokehDOF**
  - Focal Distance：**1000.0**
  - Aperture：**0.0**（关闭）

### 3.4 色调映射（Color Grading）
- Type：**ACES**（电影级色调映射）
- 全局调整：
  - Saturation：**1.05**（微增饱和度）
  - Contrast：**1.05**（微增对比度）
  - Gamma：**1.0**
  - Gain：**1.0**
  - Offset：**0.0**

### 3.5 抗锯齿（Anti-Aliasing）
- Method：**Temporal Anti-Aliasing (TAA)**
- Quality：**2**
- 勾选 **Temporal Upsampling**

### 3.6 光线追踪反射（Ray Tracing Reflections）
- 勾选 **Ray Tracing Reflections**
- Max Roughness：**0.6**（粗糙度低于0.6的表面才计算光追反射）
- Samples Per Pixel：**4**

---

## 四、反射系统配置

### 4.1 反射捕捉球体（Sphere Reflection Capture）
在测试场景中心放置：
- Influence Radius：**1000.0**
- 点击 **Capture** 按钮捕获反射
- 注意：Lumen开启后，反射捕捉作为补充，主要反射由Lumen计算

### 4.2 平面反射（Planar Reflection）
对于瓷砖/大理石地面，放置 **Planar Reflection Actor**：
- 位置：地面高度
- 勾选 **Render Two Sides**
- Distance From Plane：**0.1**
- Normal Distortion Strength：**0.1**
- 注意：平面反射性能开销大，仅用于近距离展示

---

## 五、测试场景布置

### 5.1 地面
- 放置一个 **Plane** 或 **Box** 作为地面
- 尺寸：**2000 x 2000 x 10**（单位：cm）
- 材质：使用瓷砖或大理石材质（见材质配置文档）

### 5.2 测试物体
放置以下物体用于观察光照和反射效果：
1. **Sphere**（球体）：观察高光和反射
2. **Cube**（立方体）：观察阴影和漫反射
3. **Cylinder**（圆柱体）：观察渐变光照
4. **材质球展示架**：放置不同粗糙度的材质球对比

### 5.3 相机位置
- Player Start 位置：**(0, 0, 170)**
- 初始视角：看向场景中心，距离地面约 **170cm**（人眼高度）

---

## 六、性能与质量验证

### 6.1 必开控制台命令
```
r.Lumen.DiffuseIndirect.Allow 1
r.Lumen.Reflections.Allow 1
r.Lumen.ScreenProbeGather.RadianceCache 1
r.RayTracing.Reflections 1
r.RayTracing.Shadows 1
r.SSR.Quality 3
r.VolumetricFog 1
```

### 6.2 视图模式检查
1. **Lighting Only**：验证光照是否正确
2. **Reflections**：验证反射效果
3. **Lumen Scene**：验证Lumen场景数据
4. **Ray Tracing Debug**：验证光追是否启用

### 6.3 性能指标
- 目标帧率：**60 FPS**（1080p）
- 帧时间：**< 16.6ms**
- 使用 `stat unit` 查看GPU/CPU时间
- 使用 `stat rhi` 查看渲染开销
- 使用 `stat lumen` 查看Lumen开销

## 七、常见问题排查

| 问题 | 解决方案 |
|------|----------|
| 场景全黑 | 检查定向光强度、天光是否开启、曝光设置 |
| 反射不显示 | 确认Lumen Reflections开启、材质粗糙度<0.6、光追反射启用 |
| 瓷砖反光太假 | 降低反射强度、增加法线贴图细节、使用平面反射 |
| 阴影锯齿 | 提高阴影分辨率、启用光追阴影、调整TAA质量 |
| Lumen闪烁 | 提高Screen Probe质量、启用Radiance Cache、降低动态对象移动速度 |
| 性能太低 | 关闭平面反射、降低光追采样数、降低阴影分辨率、使用FSR上采样 |
