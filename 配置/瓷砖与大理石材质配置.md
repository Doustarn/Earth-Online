# 地球Online - 瓷砖与大理石反光材质配置

## 材质总览

本配置包含4种核心材质：
1. **M_Tile_Glossy** - 亮面瓷砖（高反光，适用于卫生间、厨房）
2. **M_Tile_Matte** - 哑光瓷砖（低反光，适用于客厅、卧室）
3. **M_Marble_Polished** - 抛光大理石（镜面反光，适用于大堂、高端场所）
4. **M_Marble_Honed** - 仿古大理石（半哑光，适用于复古风格）

所有材质使用 **Substrate 材质框架**（UE5.3+），支持多层涂层、清漆、真实物理反射。

---

## 一、亮面瓷砖材质（M_Tile_Glossy）

### 1.1 材质基础设置
- Material Domain：**Surface**
- Blend Mode：**Opaque**
- Shading Model：**Substrate**
- 勾选 **Used with Landscape**（如需用于地形）
- 勾选 **Support Distance Field**

### 1.2 纹理采样节点

| 纹理名称 | 采样类型 | 用途 | 路径 |
|---------|---------|------|------|
| T_Tile_Glossy_BC | Color (sRGB) | 基础色（瓷砖颜色+填缝） | Content/Textures/Tile/ |
| T_Tile_Glossy_N | Normal (Linear) | 法线贴图（瓷砖表面凹凸+填缝凹陷） | Content/Textures/Tile/ |
| T_Tile_Glossy_R | Roughness (Linear) | 粗糙度贴图（瓷砖面光滑，填缝粗糙） | Content/Textures/Tile/ |
| T_Tile_Glossy_AO | Ambient Occlusion (Linear) | 环境光遮蔽（填缝处AO） | Content/Textures/Tile/ |

### 1.3 材质参数（可在材质实例中调整）

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| BaseColorTint | Vector3 | (1,1,1) | 基础色色调 |
| RoughnessScale | Scalar | 1.0 | 粗糙度整体缩放 |
| NormalStrength | Scalar | 1.0 | 法线强度 |
| ClearCoatAmount | Scalar | 1.0 | 清漆层强度（亮面瓷砖核心） |
| ClearCoatRoughness | Scalar | 0.05 | 清漆层粗糙度（越小越镜面） |
| TileGapDepth | Scalar | 0.5 | 填缝深度（通过法线控制） |

### 1.4 节点连接方式

```
[TextureSample: BaseColor] → [Multiply: BaseColorTint] → Substrate.BaseColor

[TextureSample: Normal] → [FlattenNormal] (NormalStrength) → Substrate.Normal

[TextureSample: Roughness] → [Multiply: RoughnessScale] → Substrate.Roughness

[TextureSample: AO] → [Multiply with Constant3(1,1,1)] → Substrate.AmbientOcclusion

[Constant: ClearCoatAmount] → Substrate.ClearCoat
[Constant: ClearCoatRoughness] → Substrate.ClearCoatRoughness
[Constant: 0.0] → Substrate.ClearCoatNormal (使用主法线)
```

### 1.5 Substrate 层级配置
- **Layer 0（基础层）**：瓷砖陶瓷体
  - Diffuse Color：来自BaseColor
  - Roughness：来自Roughness贴图（瓷砖面约0.1，填缝约0.8）
  - Normal：来自法线贴图
- **Layer 1（清漆层）**：表面釉面
  - Clear Coat：1.0
  - Clear Coat Roughness：0.03-0.08
  - 这层是产生镜面反射的关键

### 1.6 关键参数调优
- **想要更亮的反光**：ClearCoatRoughness → 0.02，Roughness贴图瓷砖面 → 0.05
- **想要更真实的瓷砖**：ClearCoatRoughness → 0.08，增加法线细节，Roughness → 0.15
- **填缝效果**：法线贴图中填缝处向下凹陷0.3-0.5，AO贴图填缝处0.3-0.5

## 二、哑光瓷砖材质（M_Tile_Matte）

### 2.1 与亮面瓷砖的区别
- 无清漆层（ClearCoat = 0）
- 基础粗糙度更高（0.4-0.6）
- 反射更柔和，无镜面高光
- 法线凹凸感更强（模拟磨砂质感）

### 2.2 核心参数
| 参数名 | 默认值 | 说明 |
|-------|-------|------|
| RoughnessScale | 1.0 | 基础粗糙度0.4-0.6 |
| ClearCoatAmount | 0.0 | 无清漆 |
| NormalStrength | 1.5 | 增强磨砂凹凸感 |
| Specular | 0.3 | 降低高光强度 |

### 2.3 节点连接
与亮面瓷砖相同，但：
- ClearCoat 输入连接 **0**
- Roughness 输出前增加 **Add(0.3)** 提高基础粗糙度
- 可选：添加 **Fuzz** 层模拟磨砂质感（Substrate Fuzz Amount = 0.2）

## 三、抛光大理石材质（M_Marble_Polished）

### 3.1 材质特性
- 天然石材纹理（ veins 纹理）
- 高抛光表面，近乎镜面反射
- 表面有细微划痕和凹凸
- 折射率高（IOR ≈ 1.5-1.6）

### 3.2 纹理采样节点

| 纹理名称 | 采样类型 | 用途 |
|---------|---------|------|
| T_Marble_Polished_BC | Color (sRGB) | 大理石纹理（底色+纹理脉络） |
| T_Marble_Polished_N | Normal (Linear) | 法线（细微凹凸+划痕） |
| T_Marble_Polished_R | Roughness (Linear) | 粗糙度（整体光滑，纹理处微变） |
| T_Marble_Vein_Mask | Linear | 纹理脉络遮罩（用于控制反射变化） |

### 3.3 材质参数

| 参数名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| MarbleTint | Vector3 | (1,1,1) | 大理石色调 |
| VeinColor | Vector3 | (0.8,0.75,0.7) | 纹理脉络颜色 |
| VeinIntensity | Scalar | 1.0 | 纹理强度 |
| RoughnessBase | Scalar | 0.08 | 基础粗糙度（抛光面） |
| RoughnessVein | Scalar | 0.15 | 纹理处粗糙度 |
| ClearCoat | Scalar | 1.0 | 清漆/抛光层 |
| ClearCoatRoughness | Scalar | 0.03 | 抛光层粗糙度 |
| NormalStrength | Scalar | 0.5 | 法线强度（大理石表面较平） |
| ScratchStrength | Scalar | 0.3 | 划痕强度 |

### 3.4 节点连接方式

```
=== 基础色 ===
[TextureSample: Marble_BC] → [Multiply: MarbleTint]
  → [Lerp: VeinColor] (Alpha = VeinMask * VeinIntensity)
  → Substrate.BaseColor

=== 法线 ===
[TextureSample: Marble_N] → [FlattenNormal] (NormalStrength)
  → [Add: ScratchNormal * ScratchStrength]
  → Substrate.Normal

=== 粗糙度 ===
[TextureSample: Marble_R] → [Multiply: RoughnessBase]
  → [Lerp: RoughnessVein] (Alpha = VeinMask)
  → Substrate.Roughness

=== 清漆层 ===
[Constant: ClearCoat] → Substrate.ClearCoat
[Constant: ClearCoatRoughness] → Substrate.ClearCoatRoughness
```

### 3.5 Substrate 高级配置
- **Layer 0**：大理石基体
  - Diffuse：大理石纹理色
  - Roughness：0.08-0.15
  - Specular：0.5（石材高光）
  - IOR：1.55
- **Layer 1**：抛光涂层
  - Clear Coat：1.0
  - Clear Coat Roughness：0.02-0.05
  - 这层产生镜面反射效果
- **可选 Layer 2**：细微划痕层
  - 使用 Anisotropy 各向异性模拟划痕方向
  - Anisotropy：0.1-0.3

### 3.6 真实感提升技巧
1. **纹理变化**：使用 WorldAlignedTexture 或 3D 纹理，避免平铺重复
2. **边缘磨损**：使用 DitheredLOD 或顶点色控制边缘粗糙度
3. **污渍变化**：添加污渍遮罩，局部提高粗糙度
4. **反射模糊**：ClearCoatRoughness 不要设为0，0.02-0.05更真实
5. **菲涅尔效应**：Substrate自动处理菲涅尔，无需手动添加

## 四、仿古大理石材质（M_Marble_Honed）

### 4.1 与抛光大理石的区别
- 无清漆层，表面经过打磨
- 粗糙度更高（0.3-0.5）
- 反射柔和，无镜面
- 表面凹凸感更强（打磨痕迹）
- 纹理更自然，有岁月感

### 4.2 核心参数
| 参数名 | 默认值 | 说明 |
|-------|-------|------|
| RoughnessBase | 0.35 | 基础粗糙度 |
| ClearCoat | 0.0 | 无清漆 |
| NormalStrength | 1.2 | 增强凹凸感 |
| Specular | 0.35 | 降低高光 |
| AgeAmount | 0.5 | 岁月痕迹强度（污渍+磨损） |

### 4.3 节点连接
在抛光大理石基础上：
- ClearCoat → 0
- Roughness → Add(0.25) 提高粗糙度
- 添加污渍层：BaseColor = Lerp(BaseColor, StainColor, StainMask * AgeAmount)
- 添加磨损层：Roughness = Lerp(Roughness, 0.6, WearMask * AgeAmount)

## 五、材质实例创建步骤

### 5.1 创建材质实例
1. 在Content Browser中右键材质 → Create Material Instance
2. 命名规则：`MI_<材质名>_<变体名>`，如 `MI_Tile_Glossy_White`
3. 双击打开材质实例

### 5.2 常用参数调整
- **白色亮面瓷砖**：BaseColorTint = (0.95, 0.95, 0.93)，ClearCoatRoughness = 0.05
- **黑色亮面瓷砖**：BaseColorTint = (0.1, 0.1, 0.1)，ClearCoatRoughness = 0.03
- **米黄大理石**：MarbleTint = (0.9, 0.85, 0.75)，VeinColor = (0.7, 0.6, 0.5)
- **灰色大理石**：MarbleTint = (0.7, 0.7, 0.72)，VeinColor = (0.5, 0.5, 0.52)

### 5.3 纹理平铺设置
在材质实例的 **Texture Coordinate** 节点中：
- 瓷砖：UTiling = 4.0, VTiling = 4.0（每块瓷砖约50cm）
- 大理石：UTiling = 1.0, VTiling = 1.0（大纹理，避免重复）
- 使用 `TextureSample` 的 `MipValueMode` = `MipLevel` 优化远距离显示

## 六、反射效果验证

### 6.1 验证清单
- [ ] 亮面瓷砖能清晰反射周围物体（Lumen Reflections）
- [ ] 反射强度随观察角度变化（菲涅尔效应）
- [ ] 填缝处无强反射（粗糙度差异）
- [ ] 大理石纹理处反射有细微变化
- [ ] 移动光源时，高光位置正确变化
- [ ] 粗糙度0.05的表面比0.2的反射更清晰

### 6.2 调试视图
- 视图模式 → **Reflections**：查看反射贡献
- 视图模式 → **Roughness**：查看粗糙度分布
- 视图模式 → **Specular**：查看高光分布
- 控制台：`r.Lumen.Reflections.Allow 1` 确保Lumen反射开启

### 6.3 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 完全没有反射 | Lumen反射关闭 / 粗糙度太高 | 开启r.Lumen.Reflections.Allow，粗糙度<0.6 |
| 反射太模糊 | ClearCoatRoughness太高 | 降低到0.02-0.05 |
| 反射太镜面不真实 | ClearCoatRoughness=0 | 设为0.02-0.08，增加法线细节 |
| 瓷砖填缝也反光 | 粗糙度贴图填缝处值太低 | 填缝处粗糙度>0.7 |
| 大理石反射发灰 | BaseColor太暗 / Specular太低 | 提高BaseColor亮度，Specular=0.5 |
| 反射有条纹/噪点 | Lumen采样不足 | 提高r.Lumen.Reflections.SamplesPerPixel |
