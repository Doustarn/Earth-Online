# 地球Online 内测服尝鲜客户端 - 使用说明

**版本**: v0.1.0 Beta
**引擎**: Unreal Engine 5.8.x
**项目位置**: `F:\Earth-online\UE5`

---

## 一、环境准备

### 1.1 安装UE5.8引擎
1. 下载安装 [Epic Games Launcher](https://www.epicgames.com/store/zh-CN/download)
2. 打开Launcher → 虚幻引擎 → 库 → 安装引擎
3. 选择 **5.8.x** 版本，安装到空间充足的盘（D/E盘均可，约30GB）
4. 安装时勾选 **"引擎源代码"** 和 **"调试符号"**（可选，用于C++调试）

### 1.2 安装Visual Studio（编译C++必需）
- Visual Studio 2022 Community（免费）
- 安装时勾选：
  - **使用C++的游戏开发**
  - **使用C++的桌面开发**
  - **Windows 10/11 SDK**

### 1.3 验证安装
- 引擎默认路径：`C:\Program Files\Epic Games\UE_5.8`
- 如装在其他盘，脚本会自动搜索 D/E/F 盘的 `EpicGames\UE_5.8`

## 二、编译项目

### 方法一：一键编译（推荐）
```
双击运行: F:\Earth-online\UE5\编译项目.bat
```
自动完成：生成VS项目文件 → 编译Development Editor

### 方法二：手动编译
1. 右键 `EarthOnline.uproject` → **Generate Visual Studio project files**
2. 打开生成的 `EarthOnline.sln`
3. 配置选择 **Development Editor** / **Win64**
4. 右键 `EarthOnline` 项目 → **生成**

### 编译成功标志
- 输出 `0 个错误`
- 生成 `UE5\Binaries\Win64\UnrealEditor-EarthOnline.dll`

## 三、打开编辑器

```
双击运行: F:\Earth-online\UE5\启动编辑器.bat
```
或直接双击 `EarthOnline.uproject`

首次打开会编译Shader，需要5-15分钟。

## 四、打包客户端

### 方法一：一键打包
```
双击运行: F:\Earth-online\UE5\一键编译打包.bat
```
自动完成：编译 → 烘焙 → 打包

### 方法二：仅打包（已编译过）
```
双击运行: F:\Earth-online\UE5\打包客户端.bat
```

### 打包输出
```
F:\Earth-online\UE5\Packaged\WindowsClient\Windows\
├── EarthOnline.exe      ← 客户端主程序
├── Engine\              ← 引擎运行时
└── ...
```

### 分发给测试玩家
将整个 `Windows` 文件夹压缩为 ZIP，发送给玩家即可。
玩家无需安装UE引擎，直接运行 `EarthOnline.exe`。

## 五、运行内测服

### 5.1 使用启动器（推荐）
```
双击运行: F:\Earth-online\UE5\内测服启动器.bat
```
菜单选项：
- **[1] 启动游戏客户端** - 运行打包好的客户端
- **[2] 创建监听服务器** - 本机作为主机，其他玩家可加入
- **[3] 加入指定服务器** - 输入IP和端口加入
- **[4] 启动专用服务器** - 无画面的纯服务器
- **[5] 打开项目编辑器**
- **[6] 编译C++项目**
- **[7] 打包客户端**

### 5.2 命令行方式

**创建监听服务器（有画面，可同时玩）：**
```
EarthOnline.exe TestMap?listen?port=7777
```

**加入服务器：**
```
EarthOnline.exe 192.168.1.100:7777
```

**专用服务器（无画面，性能更好）：**
```
EarthOnlineServer.exe TestMap?port=7777 -log
```

### 5.3 局域网联机
1. 主机运行 **创建监听服务器**
2. 查看主机IP：`Win+R` → `cmd` → `ipconfig` → 找 IPv4 地址
3. 其他玩家运行 **加入指定服务器**，输入主机IP

### 5.4 外网联机
- 需要端口映射：路由器转发 **7777端口（UDP）** 到主机
- 或使用内网穿透工具（如 frp、ZeroTier、Tailscale）

## 九、常见问题

### Q: 编译报错 "无法打开包括文件"
A: 确保安装了Visual Studio 2022和C++游戏开发组件。

### Q: 打包后运行黑屏
A: 检查 `Content/Maps/TestMap` 是否存在，打包时需勾选烘焙所有地图。

### Q: 无法连接服务器
A: 
1. 检查防火墙是否放行7777端口
2. 确认主机和客户端在同一网段
3. 外网需做端口映射

### Q: 帧率低
A: 内测版默认开启Lumen+光追，可在设置中降低：
- 关闭光线追踪
- Lumen改为软件光追
- 降低阴影质量

### Q: 编辑器启动慢
A: 首次启动编译Shader正常，后续会快。可删除 `DerivedDataCache` 清理缓存。
